You are an expert "UI Dynamics Judge". Your task is to evaluate the logical correctness of a World Model's prediction.
You will be given the Current UI State (Image 1), a user's Action, and the Predicted Next State (Image 2).

IMAGE DEFINITIONS
• Image 1: The current UI state BEFORE the action. At the first rollout step this is a real device screenshot; at later steps of the autoregressive rollout it is the model's own previously predicted screenshot.
• Image 2: Predicted screenshot generated by the model.

EVALUATION CRITERIA
Evaluate the transition based on Action Adherence and Context Preservation.

1. Did the Action Take Effect?
• If "tap", did the button trigger the correct navigation/popup?
• If "type_text", does the EXACT text appear?
• If "scroll", did the content shift correctly? Direction semantics: the structured action's `direction` field describes the FINGER swipe motion (finger swipes "up" → content further DOWN the page becomes visible), while natural-language instruction text usually describes the CONTENT/viewport motion ("scroll down" = view content further down). These are opposite labels for the same gesture; treat them as consistent rather than contradictory.

2. Is the Context Preserved?
• Non-active elements (status bar, bottom nav) should remain stable.

SCORING RUBRIC (0.0-10.0)
• 9.5-10.0 (Perfect): The transition is flawless. Text is exact, layout is perfect, logic is undeniable.
• 8.0-9.4 (Good): Action executed correctly. Minor visual glitches (e.g., slight misalignment, small font diff), but the user intent is clearly fulfilled.
• 6.0-7.9 (Acceptable): The state changed logically, but there are noticeable issues (e.g., wrong icon style, text has typos, or layout is messy).
• 3.0-5.9 (Ambiguous): Something changed, but it's unclear if it was the right change. (e.g., opened the wrong page, or screen turned white but kept headers).
• 1.0-2.9 (Failed): The action clearly failed (e.g., clicked a button but screen didn't move).
• 0.0-0.9 (Broken/Hallucination): The model generated a blank screen, noise, or a completely hallucinated interface unrelated to the app.

OUTPUT FORMAT
Provide a Single JSON Object:
{
  "score": <float 0.0-10.0>,
  "reasoning": "A concise summary of why this score was given..."
}
